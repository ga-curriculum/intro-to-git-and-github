**Learning objective:** By the end of this lesson, students will be able to distinguish between Git and GitHub, and explain the key features of GitHub, including issues and pull requests, for collaborative coding.

## What is GitHub?

GitHub is an online web application for code collaboration. Using it, we can backup and share our local Git repositories with the world. It is the most prominent online storage space for collaborative work. 

GitHub also fosters community collaboration by providing tools like [issues](https://docs.github.com/en/issues/tracking-your-work-with-issues/about-issues) for discussing ideas and problems. GitHub even adds some quality-of-life tools on top of Git, like [pull requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests) for suggesting and reviewing code changes. In short, it is a social network for developers like us!

## Why use GitHub?

GitHub plays the critical role of a cloud-based backup system - a safe place for all your work! Your code and the time you spent writing it are valuable. You don't want to risk losing it to hardware failure, etc. Using GitHub means we can push code to it on demand. And if something goes wrong, we can retrieve it easily.

GitHub is also a crucial part of collaboration, allowing developers from all over to work together to build something great by sharing their Git repositories with each other. You will use it extensively in your software engineering journey long after this course ends.

## How are Git and GitHub different? 

Git is a CLI tool that provides us with local repositories for tracking changes to our code on our own computers 💻
GitHub is an online web service that provides us with remote repositories stored in the cloud.  We can use it as a place to back up and share our the Git repositories on our own computers. ☁️
